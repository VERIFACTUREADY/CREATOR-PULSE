# Borradores en español (V2)

Contenido de la tienda en español tal como estaba en la V2 (mercado España). Desde la V2.1 el mercado principal es **EE. UU.** y el tema se publica en inglés.
Estos archivos **no forman parte del tema** para no mezclar idiomas. Si se abre un canal en español, se pueden reutilizar
como plantillas (`templates/`) o como base para la app gratuita **Shopify Translate & Adapt**. Los textos de interfaz en español siguen en `theme/locales/es.json`.
